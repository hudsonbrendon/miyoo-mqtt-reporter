mosquitto_pub (and bundled libs)
================================

The vendored binary at `mosquitto_pub` is `mosquitto-clients 1.5.7-1+deb10u1`
from Debian Buster (armhf). It links against:

    ../lib/libmosquitto.so.1     mosquitto 1.5.7-1+deb10u1 (Debian Buster armhf)
    ../lib/libssl.so.1.1         openssl 1.1.1n-0+deb10u3 (Debian Buster armhf)
    ../lib/libcrypto.so.1.1      openssl 1.1.1n-0+deb10u3 (Debian Buster armhf)

Why Buster (Debian 10) and not a newer release?
-----------------------------------------------
OnionOS ships glibc up to **2.28** under `/mnt/SDCARD/.tmp_update/lib/parasyte`.
Debian Bookworm (12) binaries require GLIBC_2.34+ which OnionOS lacks.
Buster's glibc 2.28 matches exactly, so its binaries run on the Miyoo.

The OnionOS startup hook prepends `lib/parasyte` to `LD_LIBRARY_PATH` so the
loader picks the 2.28 libc before the older system one.

Rebuilding from scratch
-----------------------

Easiest path on a Debian/Ubuntu workstation (or any machine with `ar` + `tar`):

    mkdir /tmp/mqv && cd /tmp/mqv
    curl -fsSL -o mc.deb     'http://archive.debian.org/debian/pool/main/m/mosquitto/mosquitto-clients_1.5.7-1+deb10u1_armhf.deb'
    curl -fsSL -o libm.deb   'http://archive.debian.org/debian/pool/main/m/mosquitto/libmosquitto1_1.5.7-1+deb10u1_armhf.deb'
    curl -fsSL -o libssl.deb 'http://archive.debian.org/debian/pool/main/o/openssl/libssl1.1_1.1.1n-0+deb10u3_armhf.deb'

    mkdir extracted
    for d in mc.deb libm.deb libssl.deb; do
        ar x "$d" && tar -xf data.tar.xz -C extracted/
        rm -f control.tar.* data.tar.* debian-binary
    done

    # Then copy into the repo (run from the repo root):
    cp extracted/usr/bin/mosquitto_pub                                        App/MQTTReporter/bin/
    cp extracted/usr/lib/arm-linux-gnueabihf/libmosquitto.so.1                App/MQTTReporter/lib/
    cp extracted/usr/lib/arm-linux-gnueabihf/libssl.so.1.1                    App/MQTTReporter/lib/
    cp extracted/usr/lib/arm-linux-gnueabihf/libcrypto.so.1.1                 App/MQTTReporter/lib/
    chmod +x App/MQTTReporter/bin/mosquitto_pub

    # Verify all are ARM ELFs:
    file App/MQTTReporter/bin/mosquitto_pub App/MQTTReporter/lib/lib*.so.*
    # Expected: "ELF 32-bit LSB ..., ARM, EABI5 ..."

Notes
-----
* The parasyte path injection is handled by the OnionOS startup hook at
  `boot/startup/mqttreporter.sh` — no extra config required.
* FAT32 (Miyoo SD cards) does NOT preserve POSIX symlinks. `install.sh` uses
  `rsync -aL` / `cp -RL` to dereference symlinks at copy time. If you populate
  `lib/` manually, use real file copies (not `ln -s`).
